Trámites en Departamento de Seguimiento y Evaluación

DS-1 Venta de Matriculas

Se realiza este trámite para habilitar; en un determinado rango de fechas, la venta de matrículas por CAJASISS y Cajero Virtual (Tigo Money y BNB Net) a los estudiantes. Ese rango de días entre la fecha de inicio y la fecha de fin, debe ser moderadamente amplio para que se realice una sola vez por gestión.
NO SE DEBE JUNTAR este trámite con Solicitudes de apertura del sistema para inscripciones.

Flujograma Formularios Procedimiento

DS-2 Inscripciones por WEBSIS

Se realiza este trámite para que los estudiantes se inscriban mediante Internet accediendo al sistema WEBSISS.
Se debe considerar que las fechas de apertura y cierre del sistema, estén dentro el rango de fechas solicitado para Venta de Matrículas; es decir cada vez que se abre el sistema para inscripciones, también se debe tener el sistema abierto para Venta de Matrículas.

Flujograma Formularios Procedimiento

DS-3 Inscripciones manuales por el SISS

Se realiza este trámite en CASOS MUY ESPECIALES, es decir para Alumnos con trámites de Admisión Especial, cambio de Carrera, estudios simultáneos ó traspaso de Universidad que aún no hayan completado su convalidación de Materias.
Esta inscripción solo se realiza una vez para el Estudiante, la siguiente gestión deberá inscribirse por el sistema WEBSIS.

DS-4 Registro de Notas vía WEBSISS para GESTIÓN ACTUAL

Se realiza este trámite durante el PERIODO o GESTIÓN ACTUAL, para registrar las notas de los Estudiantes.

DS-5 Registro de notas vía WEBSISS para una GESTIÓN PASADA

Se realiza este trámite, cuando existe la necesidad de MODIFICAR las notas (calificaciones de los Estudiantes) en una GESTIÓN YA PASADA.

DS-6 Registro de notas vía WEBSISS para CASOS ESPECIALES

Se realiza este trámite, cuando existe la necesidad de MODIFICAR las notas (calificaciones de los estudiantes) en casos EXCEPCIONALES que no aplican los procedimientos anteriores.

DS-7 Admisiones Estudiantes Regulares

Este trámite se realiza cuando existen Inscripciones FUERA de Calendario, las cuales requieren procesos de de reincorporaciones o cambios de Carrera.
Cada vez que se solicita abrir el Sistema para Inscripciones también se debe pedir Admisión de Estudiantes Regulares.

Flujograma Formularios Procedimiento

DS-8 Apertura del Sistema de Postulantes (SISPO)

El Decano de la Facultad, puede pedir la habilitación de este sistema para Inscripciones, Registro de Notas ó Creación de cuentas Docentes. La administración del mismo lo realiza la UTI Facultativa.
El Sistema de Postulantes del SISS está diseñado para que sea usado por cualquier Facultad.

Flujograma Formularios Procedimiento

DS-9 Creación de Perfiles de Usuarios para acceso al SISS

Se realiza este tramite cuando se requiere procesar la creación de un NUEVO USUARIO y su respectivo PERFIL para acceso al sistema SISS. Solamente si son funcionarios de la institución cuyo Manual de Funciones requiera acceso a información de este sistema.

DS-10 Creación de Impresoras y Otros Accesos para Operación del SISS

Se realiza este trámite cuando se requiere crear accesos en el SISS a impresoras instaladas en las diferentes Unidades Académicas.
Así mismo cuando se requiere otros Accesos y/o Definiciones para operaciones en el SISS.

DS-11 Admisión Estudiantes Nuevos

Este trámite se realiza antes del inicio de cada Gestión Académica, sea Anual o Semestral.
